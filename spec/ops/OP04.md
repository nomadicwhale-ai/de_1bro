# OP04 - Group by customer_id (high cardinality, ~N/10 groups)

Dataset: A (`sales_fact`). Input: dataset A (CSV chunks for Track L, Parquet for Track S). Registry name: `groupby_high_cardinality`.

Group by `customer_id` (skewed keys, up to N/10 groups). Memory-intensive.

## Result

Result rows (digested, exact): columns `customer_id`, `count_rows`, `sum_price_cents` - one row per group.

Report `checksum` and `row_count` via the result digest (spec/checksum.md, "Result digests"); `floats` as a JSON object. NULL values are digested as NULL, not as 0.

## Oracle

DuckDB over the generated Parquet files:

```sql
SELECT customer_id, count(*), sum((unit_price * 100)::BIGINT)::BIGINT FROM sales GROUP BY customer_id
```
