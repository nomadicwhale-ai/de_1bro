# OP05 - Group by (country, category, year(transaction_date))

Dataset: A (`sales_fact`). Input: dataset A (CSV chunks for Track L, Parquet for Track S). Registry name: `groupby_multi_key`.

Three-part key; `year` is the proleptic-Gregorian civil year of the date (days since 1970-01-01 converted with Hinnant's civil_from_days). NULL country is a key value.

## Result

Result rows (digested, exact): columns `country`, `category`, `year`, `count_rows`, `sum_price_cents` - one row per group.

Report `checksum` and `row_count` via the result digest (spec/checksum.md, "Result digests"); `floats` as a JSON object. NULL values are digested as NULL, not as 0.

## Oracle

DuckDB over the generated Parquet files:

```sql
SELECT country, category, year(transaction_date)::BIGINT, count(*),
                   sum((unit_price * 100)::BIGINT)::BIGINT FROM sales GROUP BY 1, 2, 3
```
