# OP01 - Full scan + aggregate

Dataset: A (`sales_fact`). Input: dataset A (CSV chunks for Track L, Parquet for Track S). Registry name: `scan_aggregate`.

One pass over all rows. `count_quantity`/`sum_quantity` skip NULL quantity (sum is NULL if every quantity is NULL). Money is summed as int64 cents (`unit_price * 100`).

## Result

Result rows (digested, exact): columns `count_rows`, `count_quantity`, `sum_quantity`, `sum_price_cents`, `min_price_cents`, `max_price_cents`, `count_returned` - exactly one row.

Report `checksum` and `row_count` via the result digest (spec/checksum.md, "Result digests"); `floats` as a JSON object. NULL values are digested as NULL, not as 0.

## Oracle

DuckDB over the generated Parquet files:

```sql
SELECT count(*), count(quantity), sum(quantity)::BIGINT, sum((unit_price * 100)::BIGINT)::BIGINT,
                   min((unit_price * 100)::BIGINT), max((unit_price * 100)::BIGINT), count(*) FILTER (WHERE is_returned) FROM sales
```
