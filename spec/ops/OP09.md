# OP09 - Top 100 customers by revenue

Dataset: A (`sales_fact`). Input: dataset A (CSV chunks for Track L, Parquet for Track S). Registry name: `top_n`.

Group by `customer_id`, sum int64 cents, take the 100 largest totals; ties broken by smaller `customer_id`. `rank` is 1..100. Result is exactly 100 rows (N >= 1000 guarantees >= 100 customers).

## Result

Result rows (digested, exact): columns `rank`, `customer_id`, `sum_price_cents` - one row per group.

Report `checksum` and `row_count` via the result digest (spec/checksum.md, "Result digests"); `floats` as a JSON object. NULL values are digested as NULL, not as 0.

## Oracle

DuckDB over the generated Parquet files:

```sql
SELECT rn, customer_id, total FROM (
                     SELECT row_number() OVER (ORDER BY total DESC, customer_id) AS rn, customer_id, total
                     FROM (SELECT customer_id, sum((unit_price * 100)::BIGINT)::BIGINT AS total FROM sales GROUP BY customer_id)) WHERE rn <= 100
```
