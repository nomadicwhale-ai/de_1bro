# OP07 - Star join sales x dim_customer x dim_product, filter, aggregate by brand

Dataset: A (`sales_fact`). Input: dataset A (CSV chunks for Track L, Parquet for Track S); tables: sales_fact, dim_customer, dim_product (`data/<table>/<size>/part-*.*`). Registry name: `star_join_aggregate`.

Join sales to `dim_customer` (customer_id) and `dim_product` (product_id); keep rows whose customer `segment = 'enterprise'`; group by product `brand`: row count and int64 cents sum.

## Result

Result rows (digested, exact): columns `brand`, `count_rows`, `sum_price_cents` - one row per group.

Report `checksum` and `row_count` via the result digest (spec/checksum.md, "Result digests"); `floats` as a JSON object. NULL values are digested as NULL, not as 0.

## Oracle

DuckDB over the generated Parquet files:

```sql
SELECT p.brand, count(*), sum((s.unit_price * 100)::BIGINT)::BIGINT FROM sales s
                   JOIN customers c ON s.customer_id = c.customer_id
                   JOIN products p ON s.product_id = p.product_id
                   WHERE c.segment = 'enterprise' GROUP BY p.brand
```
